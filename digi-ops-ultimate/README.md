# digi-ops-ultimate

Non-SEO routing pack: 13 domain router skills plus `ops-router` as an index. Each router names the preferred skill or agent per capability and what not to run alongside it. Nothing is copied or duplicated; the routers only point to skills and agents you already have installed. Where a row says "your project's agent", it applies only if your project defines one.

## Included skills

| Skill | Domain |
|---|---|
| `ops-router` | Index of all routers |
| `ops-content` | Hebrew copy and content |
| `ops-design` | Design and assets |
| `ops-social` | Facebook, Instagram, LinkedIn |
| `ops-ads-measurement` | Paid ads and reporting |
| `ops-reputation-leads` | Reputation, leads, CRM, competitors, compliance |
| `ops-dev-toolchain` | Development toolchain and security |
| `ops-video` | Video and motion graphics |
| `ops-docs-office` | Office documents |
| `ops-automation-data` | Automation and data |
| `ops-inbox-productivity` | Email, briefs, tasks |
| `ops-web-wix` | Wix site |
| `ops-memory-knowledge` | Memory and knowledge |
| `ops-mcp-tools` | MCP server selection |

SEO/GEO lives in the companion plugin `digi-seo-ultimate`.

## Install

```
claude plugin marketplace add ofirshudari1-ship-it/digi-plugins
claude plugin install digi-ops-ultimate@digi-plugins
```

## עברית

חבילת ראוטרים (לא SEO): 13 סקילים, אחד לכל תחום, ועוד `ops-router` כאינדקס. כל ראוטר מצביע על הסקיל או הסוכן המועדף ליכולת. הסקילים לא משכפלים כלום; הם מפנים לסקילים וסוכנים שכבר מותקנים אצלך.
