# hebrew-copywriter

An agent (`hebrew-copywriter`) and a short skill (`hebrew-copy-style`) for writing Hebrew business text that reads human: web and landing pages, SEO/GEO blog posts, email, WhatsApp, Facebook/Instagram/LinkedIn posts, ads, Google review replies, FAQ.

- Plain, specific, answer-first Hebrew; no AI filler; one CTA.
- RTL-safe punctuation (regular hyphen only, no long dash, careful mixed Hebrew/Latin text).
- No invented numbers, testimonials or prices: missing facts become explicit placeholders.
- Drafts only; business context (brand terms, contact details, tone) comes from your project files.
- `skills/hebrew-copy-style/examples.md` has before/after examples for common channels.

## עברית

סוכן קופירייטינג בעברית וסקיל בדיקת סגנון קצר, עם דוגמאות לפני ואחרי. כותב עברית פשוטה, ספציפית ומשכנעת, עם פיסוק בטוח ל-RTL, בלי נתונים מומצאים, וטיוטות בלבד.
