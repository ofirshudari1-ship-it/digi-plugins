# hebrew-marketing-agents

Fourteen generalized digital-marketing agents for Israeli businesses. Each agent reads business context (name, audience, tone, approved contact details and prices) from your project's `CLAUDE.md` or brand/config file, produces drafts and findings, and never sends, publishes, deletes or spends without explicit approval.

| Agent | Scope |
|---|---|
| `social-media-agent` | Facebook/Instagram calendar, post/Story/Reel briefs, page audit |
| `linkedin-agent` | LinkedIn posts, outreach drafts, company page audit (no automation) |
| `ads-agent` | Google/Meta Ads plans and drafts (never launches) |
| `reputation-agent` | Google Business Profile audit, review reply drafts |
| `cro-agent` | Form/CTA/funnel audit, evidence-based proposals |
| `ux-perf-agent` | Core Web Vitals, responsiveness, accessibility (IS 5568 / WCAG AA) |
| `compliance-il-agent` | Israeli privacy (Amendment 13), cookie consent, accessibility statement, anti-spam. Not legal advice |
| `design-brief-agent` | Visual briefs, asset specs, local image optimization |
| `email-agent` | Mailbox triage and reply drafts via any connected mail tool |
| `lead-ops-agent` | Form to CRM pipeline checks, response time |
| `analytics-agent` | Cross-channel performance report |
| `competitor-watch-agent` | Competitor site monitoring (read-only) |
| `directory-listing-agent` | Directory/citation listing prep (no accounts created) |
| `wix-apps-agent` | Installed apps/embeds audit, duplicates, cost |

Not included on purpose: SEO and GEO/AEO (use `digi-seo-ultimate`) and copywriting (use `hebrew-copywriter`).

Optional MCP tools (analytics, CRM, browser, mail, social scheduling) are used if connected, read-only by default. Nothing depends on a specific connector.

## עברית

14 סוכני שיווק מוכללים לעסקים בישראל. כל סוכן קורא את הקשר העסק מקבצי הפרויקט (`CLAUDE.md` או קובץ מותג/קונפיג), מפיק טיוטות וממצאים, ולא שולח, מפרסם, מוחק או מוציא כסף בלי אישור מפורש.
